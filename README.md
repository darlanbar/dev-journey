# Dev Journey

Rastreador de estudos gamificado para acompanhar minha jornada de aprendizado em desenvolvimento de software, com tema inspirado em Tokyo Ghoul.

> Projeto pessoal feito para me manter motivado e organizar meus estudos.

## Funcionalidades

- Sistema de níveis e XP que sobe conforme eu concluo tarefas de estudo
- Missões diárias e conquistas
- Trilha de estudos dividida em fases
- Animações e visual temático em canvas
- Progresso salvo no próprio navegador (localStorage), sem precisar de servidor ou cadastro

## Tecnologias

- HTML5
- CSS3
- JavaScript (puro, sem frameworks)
- Google Fonts

## Como usar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
